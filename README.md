# ProdDevOps

O negócio se divide em 4 pilares: Times (Fundadores, sócios, investidores, funcionários), Empresa (Unidades de negócios, fornecedores, contratos, etc), clientes e Produtos (tecnologias, canais, plataformas)

O Produto se divide em 4 pilares: Time, Peças (aplicações e dependências), Fluxo e Dados.

O Framework ProdOps adota o modelo de jornadas a partir da visão de produto digital, isso significa que existem 3 grandes jornadas no fluxo: Discovery, Delivery e Operation. As peças e o time passam pelas mesmas jornadas.

Os dados de clientes passam apenas por Operation, mas os dados dos demais pilares do negócio interagem e em conjunto contam a narrativa histórica do negócio.

Algumas jornadas são cruzadas entre as 3 grandes jornadas do fluxo do produto, Observability, Release Management, Change Management, etc.
